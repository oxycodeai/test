## 2. Compliance Posture (accepted)

- **Flipkart ToS:** Automation + multi-account technically restricted. This is a **personal-use tool** with conservative throttling — ban risk acknowledged by user. No measures that look like fraud (no spoofing, no proxies, no account farming).
- **Affiliate T&C:** Self/bulk order clauses may exclude commissions **for the link owner**. Tool shows true data; no click/order fraud, no fake conversions. Partner informed = partner's call.
- **No prohibited content:** no stolen accounts, no fake KYC, no CAPTCHA farm, no bypass of security controls for unauthorized access. User logs into **their own accounts** with **their own OTPs**.

## 3. Operational Runbook (short)

| Symptom                              | Action                                                                      |
| ------------------------------------ | --------------------------------------------------------------------------- |
| Scan all `failed` with parse error   | Check `selectors.js` vs live product page `__NEXT_DATA__`                   |
| Accounts suddenly `expired` en masse | Flipkart session policy change → health interval ↓ + re-login bulk          |
| Tunnel dead                          | `scripts/tunnel.sh` restart (cloudflared auto-reconnect flag)               |
| Chromium not launching (Termux)      | `pkg reinstall chromium`, check `CHROMIUM_PATH`, `--single-process` present |
| Orders stuck `pending`               | Orders → Pending tab → solve captcha manually                               |
| Commission totals wrong              | `affiliate_mode` check; period filter; manual reconcile                     |
